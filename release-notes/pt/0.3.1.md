# trove 0.3.1

Uma passada visual em todo o app.

## Visual

- **Camada de sistema da Apple.** Cores de sistema, cantos contínuos, uma barra lateral translúcida em lista de origem com seleção tingida, campos preenchidos com anel de foco, um controle segmentado no estilo do iOS e material de diálogo mais espesso.
- **Cards planos azul-claros.** Um fundo branco, cards azul-claros com peças brancas dentro, azul real como única cor forte e botões retangulares de 12px. O modo escuro mantém o visual de sistema.
- **Chave de visual.** Um botão temporário "Visual: novo / antes" na barra de título compara o visual novo com o anterior. A escolha fica guardada.
