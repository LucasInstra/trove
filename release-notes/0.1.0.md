# trove 0.1.0

First public release.

## What is in it

- Import of bank statements in OFX, both the SGML dialect of OFX 1.x and the XML one of OFX 2.x, with drag and drop and multi-file selection.
- Automatic recognition of the account and the card, with bank and account number read from the file itself.
- Deduplication by `FITID` and, when the bank does not keep the identifier stable, by a fingerprint of the transaction. Reimporting the same period does not duplicate anything.
- Ledger with search by description, merchant and category, plus category editing right on the row.
- In, out and net cards for the current month, computed from the local database.
- Seed categories and a SQLite database under `%APPDATA%\com.lucas.trove`.
- Signed auto-update, checked on launch and available as a manual button in Settings.

## What it does not have yet

- CSV and PDF import.
- Category dashboard, end-of-month projection and subscription detection.
- Receipts, tax tags and the tax dossier.
- Brokerage notes and portfolio.

## Notes

- Everything runs offline. No financial data leaves the computer.
- The build is not code signed, so Windows SmartScreen may warn on first run.
