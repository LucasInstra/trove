# trove 0.9.1

The data folder gets a proper name and the update notes explain themselves.

## Improved

- **A friendlier data folder.** The database now lives in `%APPDATA%\trove` instead of `%APPDATA%\com.lucas.trove`. The first time you open the app after updating, the old folder is renamed for you and nothing is lost. If it cannot be moved, the app keeps using the old one.
- **Update notes in the updates tab.** The highlights of the installed version, and of a new one when there is an update, are listed in Settings > Updates, in the app's language, each with a short explanation. There is no popup when the app opens.
