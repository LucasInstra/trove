# trove 0.1.4

Small correctness and layout pass over the 0.1.3 dashboard, plus the freed-up tile that did not make the last release.

## Freed up this month

- **A fourth KPI.** Next to income, spending and balance, the dashboard shows the parcel value of installment purchases ending this month. No previous month to compare against, so no delta.

## Hardened writes

- **Settling and paying validate first.** Marking a bill paid rejects a malformed month before touching the table, and marking a debt received on an id that does not exist is an error instead of a silent success. Both buttons surface backend errors in the banner.
- **No more silent zeros.** Manual entries and deposits validate real calendar dates, and unknown categories, accounts and goals are refused with a named error.

## Card arrangement follow-ups

- **Debts sit with the split card, the donut with the history chart.** Two small swaps in the default row order so neighbours share a subject. Saved layouts are untouched.
- **No height animations on bars.** The old single-bar styles (unused since the stacked chart) are gone, so nothing animates a height the packing pass already measured.
- **Narrow screens.** Three-option segmented controls fill the row instead of overflowing their fixed height, long installment names truncate with an ellipsis, and the cash-flow table scrolls sideways instead of squeezing. The 430px audit found no page-level sideways scroll.
